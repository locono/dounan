# 斗南 · 亚洲花都

介绍云南昆明斗南花卉市场的公益单页网站。

整站只有一个 `index.html`，纯静态、零外部依赖，打开即用。

---

## 这是什么

很多人买过玫瑰，却不知道它大概率来自昆明斗南 —— 这里是全国最大的鲜切花交易集散地。这个站点用一条主线讲这件事：**一朵花从云南的花田，到你家的花瓶，中间经历了什么**。

顺带回答旅行者真正要问的问题：什么时候开门、怎么去、这个月能看到什么花、几点去最合适。

- **非官方**：与斗南花卉市场管理方、昆明国际花卉拍卖交易中心无任何关联
- **非盈利**：无广告、无商家推荐、无外部推广链接
- **纠错邮箱**：imuse@163.com（页脚以明文展示，不使用 mailto 链接）

## 技术特点

- **零外部请求**：不加载任何字体、图片、脚本、样式。所有图形是内联 SVG，字体走系统字体栈（PingFang SC / 鸿蒙 / 微软雅黑）
- **离线可用**：单文件保存后断网也能完整浏览
- **插画原创**：12 种花卉 + 4 张场景插画全部手绘 SVG，无版权风险
- **无障碍**：正文对比度均 ≥ 4.5:1；动效尊重 `prefers-reduced-motion`；键盘可聚焦且有焦点环；图形带 `aria-label`
- **移动端**：断点 1023px / 767px；旅程与 24 小时在手机上改为横向滑动（scroll-snap）
- **SEO**：JSON-LD 结构化数据（TouristAttraction）+ meta 描述

## 设计

**标志**：六瓣花，六片花瓣各一色（粉 / 金 / 珊瑚 / 紫 / 蓝 / 绿），中心金黄花蕊。取"品种多、颜色全"之意，六色也对应站内花色体系。

**色板**：整体明亮鲜艳，各板块用不同底色形成彩虹递进 —— 旅程薄荷绿、花历奶油黄、逛市场粉、24 小时淡紫。主色鲜绿 `#177F52`，强调色橙红 `#F5381A`，辅助色玫红 / 金 / 紫 / 蓝。

**一条底线**：底色和装饰可以艳，但文字一律深色，对比度守 4.5:1。
