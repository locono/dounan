# 斗南 · 亚洲花都

一个介绍昆明斗南花卉市场的公益静态网站。

## 这是什么

用「一朵花从花田到你家」这条主线，讲清楚斗南是什么、花是怎么运出去的、这个月能看到什么花、几点开门、怎么去。

站点定位：**非官方、非盈利、无广告、无商家推荐、无代购**。页面所列信息公开整理而来，出行前请以市场方最新公告为准。发现有误可写信至 **imuse@163.com**。

支持**中英双语**：右上角「EN / 中」一键切换整页语言，默认中文，选择记在本地（localStorage），下次打开沿用。

## 页面结构

五个章节，编号 01–05，顶部导航可直接跳转。

**Hero** — 左侧标题「斗南 / 亚洲花都」+ 导语 + 三个关键信息；右侧圆角实景**轮播**（6 张花市场景，5 秒自动切换，1.1 秒淡入淡出），右下 6 个圆点可手动切换，悬停或切离标签页时暂停；左下角「亚洲花都」角标；底部 12 色花带收边。`prefers-reduced-motion` 下不自动播放，仅可手动切换。

**01 为什么是斗南** — 气候（海拔约 1900 米、紫外线强、昼夜温差大）与产业（种植基地、预冷分级、冷链干线、分销网络）两条线。右侧四条数据条：亚洲最大鲜切花集散地之一、每 10 枝 7 枝来自云南、1000+ 品种、24 小时轮转。

**02 一朵花的旅程** — 暖米白分区带（与纸底同系，上下细线分隔）。一条 SVG 路径滚入视口时以玫红虚线描出，下方挂 5 个步骤：花田 → 预冷 → 分级 → 冷链 → 花瓶。

**03 当季花历** — 12 个品种，每张卡下方 12 格花期条。点月份可实时筛选，并提示当月可遇几个品种。品种：月季、百合、康乃馨、非洲菊、满天星、洋桔梗、绣球、向日葵、勿忘我、马蹄莲、郁金香、蝴蝶兰。

**04 怎么逛** — 开放时间（主馆 9:00–18:00、夜场 20:00–22:00、门票免费）、**19:00–20:00 闭场**警示、2 个分区（花花世界主馆、周边花街）、地铁（4 号线金桂街站）、4 个时段推荐、8 条实用贴士。

**05 斗南的一天** — 三列横排卡片：02:00 花在赶路 / 10:00 最好逛的时候 / 20:00 灯下的另一面。

## 技术特点

- **零外部请求**：无 CDN、无 Web Font；照片全部本地化在 `img/` 目录。离线可用
- **实景照片**：花卉与场景均用真实摄影图（Pexels 免费许可，页脚已注明来源与非斗南实拍），仅品牌 logo 保留手写 SVG
- **动效克制**：滚动淡入、路径描线、飘落花瓣、返回顶部按钮；`prefers-reduced-motion` 下全部关闭，飘花甚至不生成
- **双语**：右上角「EN / 中」切换。中文原文在首次运行时缓存，英文对照表写在 JS 里按选择器替换，因此**HTML 主体无需改动**；`aria-label`、`<title>`、meta 描述一并切换
- **无障碍**：语义标签、键盘可聚焦、`aria-label`（双语各自一套）、正文对比度均过 4.5:1
- **响应式**：断点 960px / 720px。旅程 5 列 → 自适应；一天 3 列 → 单列图左文右 → 图上文下
- **SEO**：JSON-LD 结构化数据（`TouristAttraction`）
- **兜底**：`<noscript>` 关闭所有入场动效，JS 失效时内容照常可读

## 设计

**标志**：六瓣水滴花，六片花瓣各一色（粉 / 金 / 珊瑚 / 紫 / 蓝 / 绿），中心金色花蕊。取"品种多、颜色全"之意。用在导航、页脚、favicon 三处。飘落的花瓣取同一瓣形，但降为玫红 / 粉 / 金三色低透明度，避免抢过照片。

**排版**：编辑排版式（editorial）——暖白纸底、大留白、不对称双栏、超大半透明衬线章节编号。标题与编号用衬线，正文用无衬线系统栈，混排制造杂志感。

**色板**：

| 用途 | 色值 |
|---|---|
| 纸底 | `#FFFDF8` / `#FFF7EC` |
| 墨色 | `#2E2A26` → `#5E574F` → `#8B8278` |
| 主色 玫红 | `#FF3D6E`（深 `#D81B52`） |
| 辅助 金 / 蓝 / 紫 | `#F0A500` / `#2E9BD6` / `#8A5FE0` |

一条底线：**底色与装饰可以鲜艳，文字一律深色**。小字用的金色是深色版 `#9A6200`，因为亮金 `#F0A500` 只有 2.7:1，12px 字不达标。

**关于英文版**：为人工翻译，不是机翻直译——中文里"别跑空""慢慢淘"这类说法按语意译成了 `don't make the trip for nothing`、`browsing slowly`。品种名用常用英文名（Rose、Lily），拉丁大写名在英文模式下隐藏以免重复。若要改英文文案，改 JS 里的 `I18N` 表即可，中文原文不受影响。

## 图片来源

站内 21 张照片来自 **Pexels** 免费图库（可免费商用、无需署名）。下载时用 Pexels CDN 参数统一裁剪为 440×440（花卡）/ 760×460（场景）/ 800×800（Hero 轮播）并转 WebP。Hero 仅首张随首屏加载，其余 5 张懒加载。**照片均为花卉与花市实景参考，并非斗南实地拍摄**，页脚声明中已如实注明。换图时直接替换 `img/` 下同名文件即可（Hero 轮播张数变化时同步改 HTML 里 `.device` 内的 `<img>` 列表）。
