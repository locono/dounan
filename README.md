# 斗南 · 亚洲花都

一个介绍昆明斗南花卉市场的公益静态网站。

## 这是什么

用「一朵花从花田到你家」这条主线，讲清楚斗南是什么、花是怎么运出去的、这个月能看到什么花、几点开门、怎么去。

站点定位：**非官方、非盈利、无广告、无商家推荐、无代购**。页面所列信息公开整理而来，出行前请以市场方最新公告为准。发现有误可写信至 **imuse@163.com**。

## 页面结构

五个章节，编号 01–05，顶部导航可直接跳转。

**Hero** — 左侧标题「斗南 / 亚洲花都」+ 导语 + 三个关键信息；右侧六瓣花装置（78 秒自转、7 秒呼吸）；底部 12 色花带收边。

**01 为什么是斗南** — 气候（海拔约 1900 米、紫外线强、昼夜温差大）与产业（种植基地、预冷分级、冷链干线、分销网络）两条线。右侧四条数据条：亚洲最大鲜切花集散地之一、每 10 枝 7 枝来自云南、1000+ 品种、24 小时轮转。

**02 一朵花的旅程** — 全页唯一的高饱和实色块（叶绿渐层）。一条 SVG 路径滚入视口时描出，下方挂 5 个步骤：花田 → 预冷 → 分级 → 冷链 → 花瓶。

**03 当季花历** — 12 个品种，每张卡下方 12 格花期条。点月份可实时筛选，并提示当月可遇几个品种。品种：月季、百合、康乃馨、非洲菊、满天星、洋桔梗、绣球、向日葵、勿忘我、马蹄莲、郁金香、蝴蝶兰。

**04 怎么逛** — 开放时间（主馆 9:00–18:00、夜场 20:00–22:00、门票免费）、**19:00–20:00 闭场**警示、2 个分区（花花世界主馆、周边花街）、地铁（4 号线金桂街站）、4 个时段推荐、8 条实用贴士。

**05 斗南的一天** — 三列横排卡片：02:00 花在赶路 / 10:00 最好逛的时候 / 20:00 灯下的另一面。

## 技术特点

- **零外部请求**：无 CDN、无 Web Font、无图片文件，全部内联。离线可用
- **原创插画**：12 种花卉 + 3 张场景均为手写 SVG，无第三方素材，无版权风险
- **动效克制**：滚动淡入、路径描线、飘落花瓣、返回顶部按钮；`prefers-reduced-motion` 下全部关闭，飘花甚至不生成
- **无障碍**：语义标签、键盘可聚焦、`aria-label`、正文对比度均过 4.5:1
- **响应式**：断点 960px / 720px。旅程 5 列 → 自适应；一天 3 列 → 单列图左文右 → 图上文下
- **SEO**：JSON-LD 结构化数据（`TouristAttraction`）
- **兜底**：`<noscript>` 关闭所有入场动效，JS 失效时内容照常可读

## 设计

**标志**：六瓣水滴花，六片花瓣各一色（粉 / 金 / 珊瑚 / 紫 / 蓝 / 绿），中心金色花蕊。取"品种多、颜色全"之意。用在导航、页脚、favicon 三处，Hero 放大为装置版。飘落的花瓣复用同一瓣形与配色。

**排版**：编辑排版式（editorial）——暖白纸底、大留白、不对称双栏、超大半透明衬线章节编号。标题与编号用衬线，正文用无衬线系统栈，混排制造杂志感。

**色板**：

| 用途 | 色值 |
|---|---|
| 纸底 | `#FFFDF8` / `#FFF7EC` |
| 墨色 | `#2E2A26` → `#5E574F` → `#8B8278` |
| 主色 叶绿 | `#00A86B`（深 `#007A4C`） |
| 强调 玫红 | `#FF3D6E`（深 `#D81B52`） |
| 辅助 金 / 蓝 / 紫 | `#F0A500` / `#2E9BD6` / `#8A5FE0` |

一条底线：**底色与装饰可以鲜艳，文字一律深色**。小字用的金色是深色版 `#9A6200`，因为亮金 `#F0A500` 只有 2.7:1，12px 字不达标。
